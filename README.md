# my-sample-opencode-project

A sample project created with OpenCode.

## Description

This repository is a minimal, ready-to-use Git project that demonstrates a clean
setup: an initialized Git repository, a README, and a working remote on GitHub so
that `git commit`, `git push`, and `git pull` all work out of the box.

## Getting Started

```bash
git clone git@github.com:buhahahaha-cloud/my-sample-opencode-project.git
cd my-sample-opencode-project
```

## Usage

```bash
git status
git add .
git commit -m "Your commit message"
git push
git pull
```
